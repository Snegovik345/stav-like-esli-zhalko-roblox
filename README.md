# 🤖 Телеграм-бот техподдержки для интернет-магазина

Бот для автоматической технической поддержки интернет-магазина "Продаем все на свете". Отвечает на часто задаваемые вопросы, создает обращения к специалистам и предоставляет информацию о заказах.

## ✨ Функционал

### 📋 Основные команды:
- `/start` - Главное меню
- `/faq` - Часто задаваемые вопросы
- `/tech` - Обращение к программистам (проблемы с сайтом/оплатой)
- `/order` - Обращение в отдел продаж (проблемы с товарами)
- `/tickets` - Мои обращения
- `/contact` - Контакты поддержки
- `/help` - Список команд

### 🔧 Возможности:
- **Автоматические ответы на FAQ** - распознает ключевые слова в сообщениях
- **Создание обращений** - автоматическая маршрутизация в отделы:
  - 👨‍💻 Программисты (технические проблемы)
  - 📦 Отдел продаж (проблемы с заказами)
- **История обращений** - просмотр статуса своих заявок
- **Интуитивный интерфейс** - кнопочное меню и inline-клавиатура
